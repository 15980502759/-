# 整蛊老师模拟器

一款**单文件、离线可玩**的课堂整蛊小游戏。上课时抓紧时间恶作剧赚金币，下课铃一响就冲进课间商城补货，然后继续下一节课的快乐循环。

> 纯属虚构娱乐。游戏中的老师没有受到真实伤害，只损失了一点发型和尊严。

---

## 快速开始

1. 下载或用浏览器打开 [`整蛊老师模拟器.html`](./整蛊老师模拟器.html)
2. 选择难度，点击「开始上课」
3. 靠近老师，用拳头或道具整蛊他
4. 下课铃响后，在 1 分钟课间商城购买新道具
5. 开始下一节课，继续赚金币

不需要安装、不需要联网、不需要启动服务器，所有内容都在一个 HTML 文件里。

> **v2 新增：** 老师怒气与暴走追击、被抓罚金币、三档难度、4 个新道具、成就与本地记录、浏览器本地存档（刷新不丢进度）。
>
> **v3 新增：** 校园多场景地图（教室 ↔ 走廊 ↔ 操场 ↔ 老师办公室）、区域出口按钮、13 个成就。

## 校园地图（v3）

教室不再只有一间屋子。走到屏幕边缘就能去别的区域，右上角的「📍」会显示你当前在哪。

```text
      老师办公室  ←   走廊   →   操场
                     ↑
                   教室（右边缘出门）
```

| 区域 | 怎么去 | 能干嘛 |
| --- | --- | --- |
| 🏫 教室 | 每节课开始的位置 | 出拳、用道具、爆鸡、被追的全部主战场 |
| 🚪 走廊 | 在教室一直往右走 | 左右两个出口，走廊里揍不到老师，走错路自己撞见老师时会听到吐槽 |
| 🌳 操场 | 在走廊一直往右走 | 老师在这边散步，空气好、心情好 |
| 🏢 老师办公室 | 在走廊一直往左走 | 老师态度极好，会给你倒茶 |

- 屏幕上常驻两个方向按钮：右侧「→ 走廊 / 操场」、左侧「← 办公室」，手机不用摸到屏幕边缘也能走
- 每进一个新区域会白闪一下并弹出区域名横幅
- 区域切换后老师会重新站位：教室里继续写黑板，走廊/操场/办公室会停下来
- 一局走遍 4 个区域会解锁成就「🏃 校园跑酷」

## 玩法循环

```text
上课 4 分钟
   ↓
靠近老师 → 出拳 / 使用道具 → 每次成功整蛊 +10 金币
   ↓
下课铃响，进入 1 分钟课间
   ↓
课间商城消费金币，补充道具
   ↓
自动进入下一节课，老师会稍微更警惕一点
```

- 每节课 **4 分钟**，课间 **1 分钟**
- 每次成功整蛊固定获得 **10 金币**，无论用拳头还是道具
- 开局处于上课状态，并赠送 **火箭筒 ×1**
- 金币和道具在本局中跨课程保留
- 课间可以点击「结束课间」提前上课
- 课程持续循环，老师移动速度会随课节缓慢提升
- 整蛊会积累老师怒气，怒气满了老师会突然暴走追人

### 难度选择

开局前在标题页选择难度，以后会自动记住上次的选择：

| 难度 | 老师速度 | 被抓罚金 | 适合 |
| --- | --- | --- | --- |
| 🌱 轻松 | 更慢，怒气涨得慢 | 10 金币 | 只想轻松搞怪 |
| 🎯 标准 | 正常 | 20 金币 | 默认体验 |
| 🔥 地狱 | 更快，怒气涨得快 | 30 金币 | 想挑战反应速度 |

### 老师暴走

- 每次成功整蛊都会积累**怒气**，左上角怒气条出现后开始计算
- 怒气满格时老师会大喊一句然后**冲过来追你**
- 追击期间**暂停/继续**或者跑出教室范围都不能让他停下，唯一的办法是在追击倒计时结束前**离他远一点**
- 追击倒计时结束即视为「甩掉老师」，怒气清零，会解锁成就
- 被追上会被**没收金币**（按难度扣 10 / 20 / 30），同时被记一次「被抓住」
- 被追时屏幕边缘会泛红、怒气条闪烁，先跳走拉开距离再考虑反击

### 🥚 爆鸡（每节课 3 次）

- 每节课有 **3 次「爆鸡」** 大招，命中老师一次 **+100 金币**
- 电脑：按 `F` 或点左上角「🥚 剩余 x/3 F」按钮；手机：点右侧 🥚 爆鸡按钮
- 近距离直接命中；距离远时会丢出一颗「爆鸡」，飞过去也算命中
- 命中后老师会大喊 **“哎哟，我的jiba！”** 并原地乱跳，屏幕弹出「爆鸡成功 +100」
- 老师处于被整蛊的硬直状态时不能爆鸡，等一下再按
- 爆鸡用来之不易：一次命中会直接把老师怒气打满，有追击冷却时会立刻触发暴走
- 次数每节课自动重置，课上用完了下节课再恢复

### 课堂结算

每节课结束时，课间商城会显示上一节课的战绩与评级：

| 单节整蛊次数 | 评级 |
| --- | --- |
| ≥ 24 次 | S |
| ≥ 16 次 | A |
| ≥ 8 次 | B |
| < 8 次 | C |

## 操作方式

### 电脑端

| 操作 | 按键 / 鼠标 |
| --- | --- |
| 左右移动 | `A` / `D` 或 `←` / `→` |
| 跳跃 | `空格` / `W` / `↑` |
| 出拳 | 鼠标左键 |
| 打开道具轮盘 | 鼠标右键 |
| 使用轮盘中的道具 | 左键点击道具 |
| 快捷使用道具 | 数字键 `1`–`0`、`-`、`=` 或点击底部快捷栏 |
| 爆鸡 | `F` 或左上角 🥚 按钮（每节 3 次，+100 金币） |
| 暂停 / 继续 | `P` 或 `Esc`，被老师追时也可以暂停喘口气 |

**提示：** 右键打开轮盘后，老师不会停下来等你，选好道具就赶紧用。

### 手机端

屏幕左右两侧提供完整触控操作：

- **左侧摇杆**：移动
- **右侧「跳跃」按钮**：跳跃
- **右侧「出拳」按钮**：近身整蛊
- **右侧「道具」按钮**：打开随身背包，点选道具立即使用
- **右侧 🥚 爆鸡按钮**：每节 3 次的大招，按钮角标显示剩余次数
- 顶部按钮：声音开关、暂停

手机横屏和竖屏都能玩，横屏视野更宽。靠近老师后，「出拳」按钮会发光提示。

## 游戏机制

- **近身攻击**：与老师距离足够近时，出拳才能成功
- **自动瞄准**：使用道具时会自动朝老师方向发动
- **打击间隔**：老师被整蛊后会短暂发懵，无法立即再次命中
- **道具冷却**：上一发道具还没有落地时，不能立刻再扔一个
- **老师反应**：每件道具都有独立的动画、音效和台词，部分效果会短暂留在老师身上
- **动态课堂**：老师会在黑板前写板书、走动和碎碎念
- **课程难度**：每进入新的一节课，老师的移动速度会略微提升
- **怒气系统**：整蛊越多老师越生气，怒气会随时间缓慢消退
- **自动暂停**：切换标签页或手机切到后台时，计时会自动暂停并保存进度

### 成就与记录

暂停菜单里的「🏆 成就与记录」可以查看本机累计数据：

- 最高单节整蛊、累计整蛊、累计赚取金币、钱包历史峰值、成功甩掉老师、被老师抓住
- 13 个成就：初出茅庐、一节十次、爆破鬼才、虫虫危机、S 级捣蛋鬼、猫鼠游戏、办公室常客、百次整蛊、小富翁、全能捣蛋王、爆鸡初体验、一节课三连爆鸡、校园跑酷（v3 新增：一局走遍教室、走廊、操场、老师办公室）
- 爆鸡记录：单节最多爆鸡次数、累计爆鸡次数
- 成就达成时会弹出提示，已解锁状态会保存在浏览器里

### 本地存档

- 金币、道具、课节、难度和累计记录会自动保存在当前浏览器（`localStorage`）
- 刷新页面或重新打开后，标题页会显示「💾 已读取本地存档」，按钮变成「继续上课」
- 标题页始终是安全的：存档读回后需要再点一次「继续上课」才会正式开始新一节
- 暂停菜单里的「重新开始这一局」会清除存档重新开局
- 换浏览器、使用无痕模式或清除站点数据会丢失存档

## 技术说明

- **单文件结构**：HTML + CSS + 原生 JavaScript
- **画面渲染**：Canvas 2D
- **角色与场景**：全部使用 Canvas 图形绘制，无外部图片
- **音效**：Web Audio API 实时合成，无外部音频文件
- **界面**：DOM 覆盖层负责 HUD、商城、暂停、成就和手机控件
- **双端适配**：根据设备与视口自动切换桌面或手游布局
- **存档**：浏览器 `localStorage`，读写全部做了容错处理，存档损坏时自动回退到新开局
- **无依赖**：无框架、无 CDN、无网络请求

## 常见问题

**Q：打开后没有声音？**

A：浏览器要求先有一次用户交互才能播放声音。点击「开始上课」即可解锁音频；也可以点击顶部「♪」按钮检查是否被静音。

**Q：为什么右键没有出现道具轮盘？**

A：道具轮盘只在上课阶段且游戏未暂停时可用。手机上请点击右侧「道具」按钮打开背包。

**Q：为什么拳头没有打中？**

A：出拳需要靠近老师。走到老师身边，看到头顶出现「左键出拳 / 出拳」提示后再攻击。

**Q：为什么用不了道具？**

A：可能是背包里没有该道具、上一发道具还在飞行，或者老师仍处于短暂发懵状态。等待一秒左右再试。

**Q：商城什么时候开？**

A：每节课 4 分钟结束后自动进入 1 分钟课间商城。也可以在本节课结束后点击「结束课间」提前开始下一节课。

**Q：刷新页面会保存进度吗？**

A：会。金币、道具、课节、难度和成就记录都保存在当前浏览器里，重新打开后点「继续上课」即可接着玩。想从头开始，请用暂停菜单里的「重新开始这一局」。

**Q：老师为什么突然追我？**

A：整蛊会让老师积累怒气，左上角怒气条满格时他会暴走。冲过去拉开距离撑过追击倒计时，就能甩掉他；被追上会扣金币。

**Q：被老师追的时候攻击他有用吗？**

A：有用但不划算。打中依然奖励金币，但不会打断追击，追击期间更推荐先跑开。

**Q：爆鸡按钮为什么按了没反应？**

A：三种情况：本课 3 次已经用完（按钮会变灰，下节课恢复）、老师正被你上一发打得发懵（有 1 秒左右的硬直）、或者游戏在暂停/课间。看左上角「剩余 x/3」或手机按钮角标即可。

**Q：手机上怎么选择难度？**

A：标题页中间有一排难度按钮，点一下即可切换，上次的选择会被记住。

## 小技巧

- 拳头免费，前期多靠近老师用拳头攒出第一桶金
- 道具不用靠近也能命中，但每次整蛊仍然只奖励 10 金币
- 课间优先补便宜又好用的道具，金币留着买火箭筒也可以
- 老师被整蛊后有一段硬直时间，趁机调整站位
- 单节想拿 S 评级，需要整蛊 24 次以上
- 手机横屏时视野更完整，也方便左手摇杆、右手连招
- 怒气快满时先往远离老师的方向走，别贴着他打，给自己留好逃跑路线
- 被追时连续跳跃可以争取时间，跑出追击倒计时就安全了
- 想在「地狱」难度刷成就，记得随身多备几发道具
- 爆鸡一次 +100，但会立刻把怒气打满，建议先在教室一侧攒好金币再爆，爆完就往反方向跑
- 每节课最多 3 次爆鸡，想刷「一节课三连爆鸡」成就，记得每次爆完先躲掉追击再回来
